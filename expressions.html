Algebraic Expressions

What is an Expression?

An expression is a mathematical phrase that can include numbers, variables, and operations.

Examples

2x + 3

5a - 7

3y + 4x

Evaluating Expressions

To evaluate an expression, substitute the value of the variable and simplify.

Evaluate: 2x + 3 when x = 4

= 2(4) + 3
= 8 + 3
= 11
